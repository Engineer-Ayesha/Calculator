# 🧮  Calculator
A clean and user-friendly calculator built using **HTML, CSS, and JavaScript**.  
This project focuses on core frontend concepts like DOM manipulation, event handling, and input validation.
## 🚀 Features
- Perform basic operations: Addition, Subtraction, Multiplication, Division, Modulus
- Input validation:
  - Prevents multiple operators (e.g., ++, --)
  - Restricts operator placement at start and end
  - Handles empty input cases
- Interactive button-based UI
- Modern dark theme design
## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
## 🎯 Learning Outcomes
- Strong understanding of DOM manipulation
- Handling user input effectively
- Writing clean and structured logic
- Implementing validation in real-world scenarios
