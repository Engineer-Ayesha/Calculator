# 🧮 Calculator

A responsive Calculator web application built using **HTML, CSS, and JavaScript**. The calculator performs basic arithmetic operations through an interactive and user-friendly interface.

## 🚀 Features

- Addition, subtraction, multiplication, division
- Modulus (%) operation
- Clear all (AC) functionality
- Backspace support
- Decimal number calculations
- Responsive design for desktop, tablet, and mobile devices
- Modern dark-themed UI

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## 🧠 Problem Solving Approach

- Implemented calculator logic using JavaScript event handling.
- Managed user input dynamically through DOM manipulation.
- Handled arithmetic operations and expression evaluation.
- Added clear and backspace functionality for better usability.
- Designed a responsive layout for a seamless experience across different screen sizes.
